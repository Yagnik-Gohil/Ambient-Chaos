# 🎶 Ambient Chaos 🌌

Welcome to **Ambient Chaos**, your personal sound playground! Immerse yourself in a world of relaxing ambient sounds and create your own tranquil soundscape. Whether it's the gentle patter of rain, the calming ocean waves, or chill lo-fi beats, Ambient Chaos lets you mix, match, and control your vibe.

---

## 🌟 Features

- **Custom Ambient Soundscapes** – Mix nature sounds, musical instruments, and other fun effects.  
- **Intuitive Volume Control** – Adjust each sound individually using playful circular sliders.  
- **Relaxing Visuals** – Enjoy a calming aurora-style background while you listen.  
- **Responsive Design** – Works beautifully on both desktop and mobile screens.  
- **Fun & Playful Interface** – Designed to make ambient creation easy and delightful.

---

## 🛠 Tech Stack

- **Next.js** – Powerful React framework for building interactive UI.  
- **Tailwind CSS** – Stylish, responsive, and customizable design.  
- **HTML5 Audio & Video** – Handles smooth playback of sounds and background visuals.  
- **Custom Circular Slider** – Fun and responsive knob controls for volume.

---

## 🚀 Getting Started

#### 1. Clone the repository:
```bash
git clone https://github.com/Yagnik-Gohil/Ambient-Chaos.git
```

#### 2. Navigate to the project folder:
```bash
cd Ambient-Chaos
```

#### 3. Install dependencies:
```bash
npm install
```

#### 4. Run the application:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser and start creating your perfect ambient chaos! 🎵✨

---

## 🎧 How to Enjoy

1. Click on a sound card to activate it.  
2. Adjust the circular knob to control volume.  
3. Layer multiple sounds together to create your own ambient symphony.  
4. Put on headphones for the full immersive experience.
